Step 1

The product

Who uses the tool decides which standards apply. Tools that pupils use are checked against all 13; staff-only tools against 8.

Step 2

The 13 standards

For each check, record the strongest evidence you have. A supplier saying "yes" is a claim; a document you can file is evidence; seeing it work in a trial is verification.
