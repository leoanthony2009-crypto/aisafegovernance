## Known limitations (stated, not hidden)
1. **Manual assistive-technology testing not performed.** Accessibility evidence is automated (axe-core) plus scripted keyboard/journey checks. A manual screen-reader pass (NVDA/VoiceOver) is recommended before describing the course as WCAG-verified.
2. **PDFs are untagged.** They contain real selectable text with correct reading order, but are not tagged/validated PDF/UA. The accessible HTML version of each document is the primary format and is offered alongside every PDF.
3. **Certificate PDF is produced via the browser's print dialog** (stated on the page), because client-side PDF generation is excluded by the no-external-code, strict-CSP architecture. The downloadable certificate file is accessible HTML.
4. **Automated download clicks** occasionally throttle under rapid scripted repetition (a Chromium automation artefact); single user-initiated clicks behave normally and were verified in isolation.
