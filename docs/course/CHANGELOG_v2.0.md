# AISG 4Cs Micro-Course — Change Log, v1.7 → v2.0 (20 October 2026)

## Retained (unchanged)
- All 13 lessons, 3 scenarios and the 6-question knowledge check (content independently reviewed at v1.7)
- Self-contained single-file architecture, strict CSP, zero external requests, embedded fonts
- Privacy-first model: no accounts, tracking or analytics; local-only progress
- Navigation, progress, resume, mobile menu and bottom bar, accessibility structure
- Trinidad & Tobago edition v1.0 (separate file, untouched by this release)

- Resources page rebuilt as a grouped **Resources and downloads** library (Use in school / Run this training yourself / Your record)

- Certificate block extended: course version, completion status, first-attempt score, document reference, self-declared-name statement, "Independent, non-accredited professional learning"; print output isolated to the certificate alone
- Quiz page now states the completion threshold explicitly
- Landing page: learning-outcomes card and privacy summary added
- Storage key unchanged (`aisg-4cs-course-v2`) — existing learners' progress is preserved

## v2.0.1: full-page certificate and digital badge

- CPD certificate is again a real PDF built in the browser: full-page A4 landscape, two pages (certificate, then CPD record with reflection and sign-off), embedded fonts, selectable text, screen-reader tags, PDF/A and PDF/UA metadata. It replaces the print-dialog and HTML certificate.
- Layout follows NHS and GOV.UK certificate practice: full-bleed issuer band, plain left-aligned type, clear name / course / date hierarchy, a row of key facts, learning outcomes, credential ID with a verification link, and the disclaimer in the footer.
- Digital badge restored: Open Badges 3.0 PNG at 1200 × 1200 px with the credential baked in, plus a new full-page A4 portrait badge sheet (PDF) and an Add to LinkedIn link.
- The completion screen shows full-page previews drawn from the same page model as the PDFs.
- Credentials and public badge files now point to aisafegovernance.netlify.app; the badge records six knowledge-check questions; /verify reads the question count from the badge.
